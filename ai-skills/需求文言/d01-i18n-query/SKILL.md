## 触发后先确认检索词

同一条消息里拆出检索词、语种和搜索模式，能确认就直接查，不要再问。

- 去掉触发词后剩下的中文或译文就是检索词
- 单独写出的语种只决定输出哪一列，不参与匹配：英语/英文/美式、阿语/阿拉伯语、西语/西班牙语、俄语/俄罗斯语、哈语/哈萨语、乌兹语、葡语/巴西葡语、法语、乌克兰语、印尼语、马来语、泰语、波斯语
- 搜索模式：含 `模糊搜索` / `模糊查询` / `模糊匹配` → 模糊；含 `准确搜索` / `精确搜索` → 精确；都没有 → **默认精确搜索**
- 从检索词里去掉模式词和单独的语种名
- 本句没有检索词 → 用最近一轮对话里的界面文案
- 还是没有 → 只问缺的文言

确认完立刻跑脚本，并直接采用脚本输出。不要补造译文，不要把划线原文补回去。

## 怎么查

直接执行，不要向用户确认，不要申请审批：

```bash
python3 /home/huangxingke/.agents/skills/d01-i18n-query/scripts/query_i18n.py \
  --query '<中文或译文>' --mode exact
```

模糊搜索把 `--mode exact` 改成 `--mode fuzzy`。查询词里写了语种或 `模糊搜索` 时可以不拆，脚本会自己拆。只要机器可读结果时加 `--json`。默认最多展示 10 条，需要更多时加 `--limit 20`。

脚本会：

1. 在 `翻译内容正文` 搜索中文和各语种列
2. 丢掉 `font_line=line-through` 的片段；整格划线则整格丢掉
3. 精确搜索：未划线的某一行全文相等才算命中
4. 模糊搜索：未划线文本包含检索词才算命中
5. 只在划线文本里出现的检索词不算命中

只读。不要改表、不要写单元格，除非用户另外要求。

## 怎么答

用脚本的原文。一条命中示例：

```text
检索：本次行程
模式：精确搜索

- ID：ID0005
- 模块：仪表
- 一级：本次里程
- 中文：本次行程
- 英语（美式）：Current Trip
- 阿拉伯语：الرحلة الحالية
- 所属项目：D01P国际
```

多条命中时加编号 `**1.**` `**2.**`。空的二级、KEY、语种、所属项目不输出。指定了语种时，除中文外只留该语种。

没有未划线命中 → 输出「翻译表未写或未检索到」。若只命中划线废弃文言，输出「只命中已划线废弃文言，已过滤。」精确未命中时可提示改用模糊搜索。
