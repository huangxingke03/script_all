## 触发后先确认检索词

查询条件是 **中文文言** 或 **英文文言**。同一条消息里拆出检索词和搜索模式，能确认就直接查，不要再问。

- 去掉触发词后剩下的中文或英文就是检索词
- 搜索模式：输入含 `模糊搜索` / `模糊查询` / `模糊匹配` → 模糊；含 `准确搜索` / `精确搜索` / `准确查询` / `精确查询` → 精确；都没有 → **默认精确搜索**
- 从检索词里去掉上述模式词
- 本句没有检索词 → 用最近一轮对话里的界面文案或截图文字
- 还是没有 → 只问缺的文言

确认完立刻跑脚本并按模版输出。

## 怎么查

直接执行，不要向用户确认，不要申请审批：

```bash
python3 /home/huangxingke/.agents/skills/kp31-i18n-query/scripts/query_i18n.py \
  --query '<中文或英文文言>' --mode exact
```

模糊搜索把 `--mode exact` 改成 `--mode fuzzy`。查询词里写了 `模糊搜索` 时也可不传 `--mode`。只要机器可读结果时加 `--json`。默认最多展示 10 条，需要更多时加 `--limit 20`。

脚本会：

1. 默认精确搜索：`中文` 或 `英文（澳式）-更新版` 全等才算命中
2. 指定模糊搜索：用 `+record-search` 按包含匹配，再按精确、前缀、包含排序
3. 英文只用更新版，不要输出原版废弃列和二级功能
4. 输出里带上本次模式：精确搜索 / 模糊搜索

只读。不要改表、不要写记录，除非用户另外要求。

## 怎么答

结论只输出这四项，顺序固定：`ID`、`模块`、`中文`、`英文`。不要编造未检索到的译文。英文列用表内「英文（澳式）-更新版」。不要输出二级功能、备注、原版英文。

一条命中：

```text
检索：年
模式：精确搜索

- ID：ID1230
- 模块：Launcher
- 中文：年
- 英文：Year
```

多条命中时加编号 `1.` `2.` `3.`：

```text
检索：折叠
模式：模糊搜索

**1.**
- ID：ID1235
- 模块：Launcher
- 中文：折叠
- 英文：Collapse

**2.**
- ID：ID3441
- 模块：System UI
- 中文：后视镜折叠
- 英文：Mirror Folding
```

没有命中 → 输出「词条表未写或未检索到」，不要补造翻译。精确未命中时可提示改用模糊搜索。命中很多时先给最相关的，并说明还可继续缩小检索词。
